# Sistema visual

Azul marino #14243B, azul #2855D9, naranja #EA6B32, fondo #F3F5F9, texto #182234. Inter y Plus Jakarta Sans con alternativas locales. Iconos Lucide y marca de ladrillos propuesta.

Espaciado principal de 8 puntos con ajustes de 4. Fondos neutros dominantes (60), estructura y texto (30), acentos moderados (10): guía cualitativa, no superficie azul obligatoria. La jerarquía depende de tamaño, peso, espacio y contraste.

Hick: una acción primaria contextual, opciones avanzadas agrupadas. Miller: formularios agrupados sin imponer siete opciones. Parkinson: menos pasos repetidos sin temporizadores artificiales. Fitts: controles táctiles de 48 px y acciones alcanzables.

PC: catálogo/carrito simultáneos; tablet: columnas flexibles; celular: navegación inferior y carrito con total. Se comprueban 390, 834 y 1440 px más 320 px, zoom y orientación. Foco, etiquetas, errores y estados deben ser accesibles. Los avisos no sustituyen mensajes persistentes de error.
